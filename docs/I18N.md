# Internacionalización (i18n)

El portfolio soporta **español** y **inglés**. No hay routing por locale; el idioma se controla con un toggle en la navbar.

## Archivos

| Archivo | Rol |
| ------- | --- |
| `src/lib/i18n/types.ts` | Interfaz `Translations` (contrato de claves) |
| `src/lib/i18n/es.ts` | Traducciones en español |
| `src/lib/i18n/en.ts` | Traducciones en inglés |
| `src/lib/i18n/LanguageContext.tsx` | Provider + hook `useLanguage()` |
| `src/lib/i18n/localeUtils.ts` | Detección de región ES y keys de storage |

## Uso en componentes

```tsx
'use client';
import { useLanguage } from '@/lib/i18n/LanguageContext';

export default function Example() {
    const { t, language, setLanguage, toggleLanguage } = useLanguage();
    return <p>{t.hero.bio}</p>;
}
```

- `setLanguage('es' | 'en')` — cambio explícito con persistencia
- `toggleLanguage()` — alterna entre ES y EN

## Añadir una nueva clave

1. Añadir la clave en `types.ts` bajo la sección correspondiente (`nav`, `hero`, `common`, etc.).
2. Traducir en **ambos** `es.ts` y `en.ts`.
3. Usar `t.seccion.clave` en el componente — nunca hardcodear texto user-facing.

## Contenido bilingüe en datos

Los proyectos usan `Record<Language, string>` para descripciones:

```ts
description: {
    es: 'Texto en español',
    en: 'Text in English',
},
```

Acceso: `project.description[language]`.

## Persistencia y primera visita

| Key | Valores | Uso |
| --- | ------- | --- |
| `portfolio-lang` | `es` \| `en` | Idioma elegido por el usuario |
| `portfolio-lang-prompt-dismissed` | `true` | Banner de sugerencia ya cerrado |

**Primera visita (sin `portfolio-lang`):** el sitio carga en **inglés** por defecto.

El script en `layout.tsx` sincroniza `document.documentElement.lang` antes del primer paint si hay preferencia guardada.

## Banner de sugerencia de español

Componente: `LanguagePrompt` — banner fijo inferior, no bloqueante.

Se muestra solo si:

1. No existe `portfolio-lang` en `localStorage`
2. No existe `portfolio-lang-prompt-dismissed`
3. `detectSpanishRegion()` es `true`

### Señales de detección (`localeUtils.ts`)

| Señal | Ejemplo |
| ----- | ------- |
| Idioma del navegador | `navigator.languages` empieza con `es` |
| Región ISO | `es-CO`, `es-MX`, `es-ES`, etc. |
| Zona horaria | `America/Bogota`, `America/Mexico_City`, `Europe/Madrid`, … |

Sin geolocalización ni APIs externas.

### Acciones del banner

- **Aceptar** → `setLanguage('es')` + dismiss
- **Descartar** / **Escape** → mantiene inglés + dismiss
- Texto bilingüe (ES + EN) porque el sitio arranca en inglés

Claves i18n: `common.language_prompt_*`

## Reglas

- Todo texto visible al usuario debe pasar por i18n.
- Aria-labels y mensajes de error también.
- Nombres propios (SkyVault, SelanFlow, GitHub) no se traducen.
- Mantener paridad ES/EN: si añades una clave en un idioma, añádela en el otro.
- No revertir el default `'en'` en primera visita; el banner cubre la sugerencia para regiones ES.
